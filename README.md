# حساب ماجد — نظام محاسبة الناقل الخارجي

تطبيق ويب عربي (RTL) لإدارة حسابات ناقل خارجي: الرحلات، السائقون، المصروفات،
أسعار المسارات، وكشف حساب شهري جاهز للطباعة في صفحة A4 واحدة.

## التقنية

- صفحة HTML واحدة قائمة بذاتها — بلا خادم وبلا عملية بناء
- قاعدة بيانات **Supabase (PostgreSQL)** مع حماية على مستوى الصف (RLS)
- تسجيل دخول باسم مستخدم، وصلاحيات: مالك / محرِّر / اطلاع فقط
- مزامنة لحظية بين الأجهزة، وعمل محلي عند انقطاع الإنترنت
- استيراد رحلات من ملفات Excel مع تهيئة تلقائية للأعمدة والتواريخ

## ملاحظة أمنية

المفتاح الظاهر في الكود هو `publishable key` من Supabase، وهو **مُصمَّم ليكون علنياً**.
حماية البيانات تعتمد على سياسات RLS داخل قاعدة البيانات، لا على إخفاء المفتاح.
لا يستطيع أي زائر غير مسجَّل قراءة أي صف.
